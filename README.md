Overview: This project fits several parametric models to daily percentage log-returns of 25 DJIA stocks using Maximum Likelihood Estimation (MLE). It compares models using AIC/BIC and evaluates their accuracy in estimating 1% Value-at-Risk.+1Implemented Models:Gaussian: $X \sim N(\mu, \sigma^2)$.Mixture of Gaussians (MoG): 2 and 3 components.Weighted Sum of $\chi_1^2$ Variables: PDF computed via characteristic function inversion.+1Location-Scale Non-Central $t$ (NCT): $Y = \mu + \sigma T$.Key Findings:The NCT model is frequently selected as the best fit by the BIC criterion due to its balance of flexibility and parsimony (4 parameters).+1Gaussian models consistently underestimate left-tail risk.
